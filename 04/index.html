Core Web Technologies

HTML: 구조적 뼈대

웹 콘텐츠의 의미와 구조를 정의하는 디지털 청사진입니다. 요소(Element)를 통해 정보의 위계를 세웁니다.

  • Root & Meta 데이터 관리
  • 시맨틱 태그를 통한 구조화

CSS: 시각적 입힘

문서의 스타일과 레이아웃을 담당하는 인테리어 역할을 합니다. 선택자(Selector)를 통해 디자인을 분리 관리합니다.

Flexbox

1차원 레이아웃

CSS Grid

2차원 레이아웃

JS: 동적인 뇌

사용자 행동에 반응하고 생명력을 불어넣는 동력 엔진입니다. JIT 컴파일 방식을 통해 극대화된 속도를 보장합니다.

  • DOM 요소를 통한 실시간 제어
  • 서버 통신 및 데이터 저장
